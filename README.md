# 🎲 FF14 Job Picker（FF14 今天玩什么？）

一个为《最终幻想 14》开黑场景设计的**职业随机选择器**：按副本类型分配职能槽位，按每位玩家的排除规则随机抽职业，避免连续重复，支持局域网内跨设备访问。

> 本工具与 SQUARE ENIX 无关，仅为玩家自用的组队小工具。

## ✨ 功能

- **副本职能配置**：内置四人本（1 防护 / 1 治疗 / 2 进攻）、八人本（2 / 2 / 4）、二十四人本（1 / 2 / 5），可随时增删改副本模板
- **动态玩家**：临时加减玩家，人数即实际抽取人数，超出副本槽位会友好提示
- **排除规则**：每个玩家可排除整个职能或单个职业，职能 ↔ 职业复选框双向联动
- **联动规则**：可配置"当玩家 A 抽到某职能时，玩家 B 排除某职能"，支持限定仅在特定副本生效（如四人本防护不重复）
- **防重复抽取**：防护/治疗职能回避最近 3 次抽到的职业，且越久没抽到的职业权重越高；进攻职能排除上一次结果
- **随机分配**：约束满足式回溯搜索，只要存在合法分配方案就一定能找到；同职能多槽位允许重复职业
- **历史记录**：每次结果自动存档（SQLite），可单条删除或清空
- **现代化 UI**：毛玻璃质感、弹簧动画、移动端自适应、支持 `prefers-reduced-motion`

## 🚀 快速开始

前置要求：**Node.js ≥ 18**（better-sqlite3 为原生模块，npm 会自动下载预编译二进制；若无预编译包则需要本地编译工具链）。

```bash
npm install
npm start
```

打开 `http://localhost:3000`。局域网内其他设备访问 `http://<你的局域网IP>:3000`（启动时控制台会自动打印）。

数据库为嵌入式 SQLite（`data/jobs.db`），**首次启动自动创建**并写入 21 个职业、职能分组与两位示例玩家，无需安装任何数据库服务。删除 `data/` 目录即可完全重置。

### 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址；仅本机使用可改为 `127.0.0.1` |

### 自定义背景图（可选）

将任意图片命名为 `public/bg.jpg`（建议压缩到 5MB 内）即可作为页面背景（30% 透明度）。**仓库不附带背景图**，缺失时自动使用内置渐变背景，页面功能不受影响。

## 🍎 macOS 开机自启（可选）

双击 `install-autostart.command` 一键安装 launchd 服务（自动解析 node 路径、崩溃自动重启）。
从 GitHub 下载的脚本首次运行若被 Gatekeeper 拦截，请**右键 → 打开**。
卸载双击 `uninstall-autostart.command`。Windows / Linux 用户请忽略这两个脚本，用系统自带的方式托管 `node server.js` 即可。

## ⚠️ 安全提示

服务**无任何鉴权**且默认监听 `0.0.0.0`，局域网内任何人都可以修改你的配置和数据。请仅在可信局域网内使用，**不要将端口转发到公网**。仅自己使用时建议 `HOST=127.0.0.1 npm start`。

## 🧱 技术栈

- 后端：Node.js + Express + better-sqlite3（嵌入式 SQLite，WAL 模式，外键约束）
- 前端：原生 HTML / CSS / JavaScript，零构建、零框架
- 随机算法：槽位随机分配采用回溯搜索（约束满足），职业抽取按职能区分策略（防护/治疗为回避 + recency 加权，进攻为排除上次结果）
